Introduction
•
Web applications represent the primary attack surface of the modern 
internet.
•
Traditional vulnerability scanners rely on static rule-matching, which 
are inadequate against modern Single-Page Applications (SPAs) and 
dynamic APIs.
•
AWAP-AI is a full-stack autonomous web application penetration 
testing tool.
•
It combines classical penetration testing methodology with an AI layer 
that reasons about attack paths, generates context-aware payloads, and 
evaluates vulnerabilities.
Problem Statement
1. Problem Definition:
•
Modern web applications are massive and highly complex to secure.
•
Attackers adapt rapidly; defenders use slow, fixed-rule tools.
•
Single 
point-in-time 
scans 
create 
a 
backlog 
of 
undetected 
vulnerabilities.
2. Expected Outcome:
•
An autonomous AI-driven tool capable of executing all phases of a 
security assessment  such as reconnaissance, enumeration, vulnerability 
identification, and reporting.
•
Zero manual intervention required between testing phases.

Objectives
1.
To Design an automated tool architecture utilizing multiple specialized 
engines (Recon, Crawler, Attack) orchestrated via a central message 
bus.
2.
To Develop intelligent payload generation engines and Machine 
Learning classifiers that accurately analyze HTTP responses and detect 
anomalies.
3.
To Implement a comprehensive testing tool that produces 
professional, CVSS-scored findings with minimal false positives.

Methodology
The tool operates via a seamless workflow pipeline:
1.
Scope Verification: Normalizes the target and logs authorization.
2.
Reconnaissance: DNS enumeration, port scanning, and OSINT gathering.
3.
Crawl & Mapping: Headless Playwright crawling extracting APIs and parameters.
4.
Attack Execution: Running vulnerability modules (SQLi, XSS, CMDi, SSRF) utilizing 
a 5-layer mutation engine.
5.
AI Analysis: Using BERT and Isolation Forests to classify findings and reduce false 
positives.
6.
Reporting: Generating CVSS-scored outputs.

Messaging: Redis Streams.

Results
•
A professional, SOC-aesthetic live dashboard.
•
Real-time scan progress streaming using native WebSockets.
•
Instant classification of High/Critical vulnerabilities via AI inference.
•
Auto-generated Proof of Concept (PoC) code for developers.
•
Downloadable security reports in PDF/JSON/DOCX formats.
Conclusion
•
Security testing must evolve beyond standard signature scans.
•
This tool successfully simulates a real bug bounty researcher's workflow.
•
Orchestrates advanced web crawling and intelligent fuzzing seamlessly.
•
Deep Learning response classification discovers flaws efficiently and reliably.
Future work

Integrate directly into Enterprise CI/CD pipelines (e.g., GitHub Actions).
